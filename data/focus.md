# 최근 작업 (AI REVIEW 입력)

AI REVIEW가 "요즘 무엇을 하고 있는지"를 쓸 때 쓰는 **유일한 근거 파일**이다.
커밋 집계(`data/stats.json`)는 수와 시점만 증명하므로 업무 종류를 추론할 수 없다.
그래서 사람이 직접 여기에 적고, AI는 여기 적힌 것만 인용한다.

## 작성 규칙

- **대외비 금지.** 고객사 실명, 내부 저장소·모듈명, 미공개 일정, 계약·매출 세부, 보안 구현값(알고리즘·키 구성·저장 위치)은 쓰지 않는다.
- 이미 `index.html`에 공개된 범위이거나, 공개해도 무방한 기술 주제만 쓴다.
- 한 줄에 하나. `- YYYY-MM: 내용` 형식. 최신이 위로 온다.
- 6개월이 지난 항목은 지운다. 오래된 항목이 "최근"으로 읽히면 안 된다.
- 확정되지 않은 계획은 쓰지 않는다. 진행 중이거나 끝난 일만 쓴다.

## 항목

- 2026-08: Windows에서 축적한 클라이언트 구조를 macOS로 이식 중. Swift·AVFoundation 기반으로 실시간 얼굴 인증과 감시 정책 경로를 다시 세우고, 에이전트와 서버 사이 REST 연동을 클라이언트 측에서 구현하고 있다.
- 2026-08: AI 코딩 하네스(Claude 구현 · Codex 리뷰)를 실무 개발 절차 안에 통제된 형태로 도입해 운영 중. 설계 판단과 최종 승인은 사람이 맡는 역할 분리를 먼저 정의했다.
- 2026-07: 얼굴 인증 Credential Provider와 Identity Provider 클라이언트를 제품 형태로 정리. 물리 PC·VDI·망분리처럼 현장마다 다른 전제를 예외 처리 대신 공통 인증 흐름으로 흡수하는 작업.
